# Retrospective template

Write one after each episode's final cut, and save it in the work directory as `docs/E0N-retro.md`. Record only what differs from the previous episode, and why.

```markdown
# Episode N retrospective

## Numbers

| Item | This episode | Previous episode |
|---|---|---|
| Segments / cuts | | |
| Planned length / final length | | |
| Video submissions | | |
| Cuts that passed first time / total cuts | | |
| Video tool usage (quota % / credits / cost) | | |
| Time from storyboard to final cut | | |

## Rework

| Shot | Problem | Cause | Fix |
|---|---|---|---|

## New this episode

- Rule: …
  - Source: which cut, and what went wrong.
  - Written into: `references/xxx.md` / `scripts/xxx`.

## My mistakes

- What went wrong, what it affected, how to prevent it next time.

## Decisions for the user

- …
```

When you finish, check every "Written into" item: open that file and confirm the rule is really there.
