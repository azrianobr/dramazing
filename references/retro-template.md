# 复盘模板

每集定稿后写一份，放在作品目录的 `docs/E0N-复盘.md`。只记和上一集不同的地方，以及原因。

```markdown
# 第 N 集复盘

## 数字

| 项目 | 本集 | 上一集 |
|---|---|---|
| 段 / 切 | | |
| 计划时长 / 成片时长 | | |
| 出片提交次数 | | |
| 一次过的切数 / 总切数 | | |
| Grok 用量（Imagine %） | | |
| 写分镜 → 定稿用时 | | |

## 返工

| 镜头 | 问题 | 原因 | 怎么改的 |
|---|---|---|---|

## 这集新学到的

- 规则：……
  - 来源：哪一切、出了什么问题。
  - 已写进：`references/xxx.md` / `scripts/xxx`。

## 我犯的错

- 错在哪，影响了什么，以后怎么防。

## 需要用户定的

- ……
```

写完检查：每条「已写进」都打开那份文件确认真的写了。
