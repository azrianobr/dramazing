# 회고 템플릿

한 화를 확정할 때마다 하나씩 써서 작품 폴더의 `docs/E0N-회고.md`에 둡니다. 앞 화와 달라진 점과 그 이유만 적습니다.

```markdown
# N화 회고

## 수치

| 항목 | 이번 화 | 앞 화 |
|---|---|---|
| 세그먼트 / 컷 | | |
| 계획 길이 / 완성본 길이 | | |
| 영상 생성 제출 횟수 | | |
| 한 번에 통과한 컷 수 / 전체 컷 수 | | |
| 영상 도구 사용량(한도 % / 크레딧 / 비용) | | |
| 콘티 작성 → 확정까지 걸린 시간 | | |

## 재작업

| 컷 | 문제 | 원인 | 고친 방법 |
|---|---|---|---|

## 이번 화에서 새로 배운 것

- 규칙: ……
  - 출처: 어느 컷에서 무슨 문제가 있었는지.
  - 반영한 곳: `references/xxx.md` / `scripts/xxx`.

## 내가 한 실수

- 무엇이 잘못됐고, 무엇에 영향을 줬고, 앞으로 어떻게 막을지.

## 사용자가 정해야 할 것

- ……
```

다 쓰면 확인합니다: 「반영한 곳」 항목마다 그 파일을 열어 정말 적혀 있는지 확인합니다.
