# 데이터 형식

작품 하나는 폴더 하나입니다(아래에서는 「작품 폴더」라고 부릅니다). 폴더 안에 JSON 세 파일이 있고, 스크립트는 이 세 파일만 읽습니다.

| 파일 | 내용 | 작성자 |
|---|---|---|
| `project.json` | 작품 정보, 화풍, 도구 선택, 인물 / 장소 / 소품 | AI 어시스턴트가 원문을 읽고 작성. `writing.md` 참고 |
| `script.json` | 대본: 화마다 몇 장, 장마다 비트 목록 | AI 어시스턴트가 화별로 작성 |
| `storyboard.json` | 콘티: 화마다 몇 세그먼트, 세그먼트마다 몇 컷 | AI 어시스턴트가 화별로 작성 |

스크립트가 만드는 파일:

| 위치 | 내용 |
|---|---|
| `tasks.json` | 이미지 생성 작업 목록(`frames.mjs plan`이 작성) |
| `sheets/<ID>.png` | 설정화: 인물, 장소, 소품마다 한 장 |
| `frames/<세그먼트 번호>/f<N>.png` | 콘티 그림: 컷마다 한 장이며, 영상 생성의 첫 프레임이기도 함 |
| `video/` | 프롬프트, 컷 원본 영상, 편집한 세그먼트, 한 화 전체, 자막(폴더 이름은 `--dir`로 바꿀 수 있음) |
| `_logs/` | 이미지 생성 사용량, 영상 생성 기록, 영상 도구 사용량 |
| `_bak/` | 스크립트가 JSON을 고치기 전에 자동으로 백업한 이전 버전 |

전체 예시는 `examples/渡口/`(중국어, 6화)를 보세요. 영어와 한국어는 한 화짜리 작은 예시가 하나씩 있습니다: `examples/last-tram/`, `examples/majimak-jeoncha/`. 빈 템플릿은 `templates/<언어>/`에 있습니다.

## project.json

```json
{
  "title": "작품명",
  "source": "story.txt",
  "episodes": 6,
  "language": "zh",
  "aspect": "16:9",
  "targetSeconds": [130, 150],
  "style": "사실적인 영화 질감, 1930년대 민국 시대 강남, 자연광, 은은한 필름 그레인",
  "images": { "provider": "manual", "cmd": "(provider가 cmd일 때) 이미지 생성 명령 템플릿" },
  "video": { "target": "grok", "durations": [6, 10], "head": "(선택) 프롬프트 첫머리의 화질 문장을 바꿈" },
  "characters": [
    {
      "id": "C01",
      "name": "인물명",
      "alias": { "zh": "梳双麻花辫的年轻女子", "en": "the young woman with long braids" },
      "trait": { "zh": "左眼浑浊发白，右眼正常，全程保持", "en": "His left eye is clouded milky white ..." },
      "sheet": "설정화 프롬프트(영어나 중국어 모두 가능)"
    }
  ],
  "scenes": [
    { "id": "S01", "name": "장소명", "sheet": "설정화 프롬프트",
      "ambient": { "*": "배가 물결에 따라 살짝 흔들리고, 선실 밖으로 안개가 천천히 흘러간다.", "짙은 안개 낀 이른 아침": "빛에 따라 따로 쓴 환경 움직임" } }
  ],
  "props": [ { "id": "P01", "name": "소품명", "sheet": "설정화 프롬프트" } ]
}
```

- `language`: 이야기 언어. `zh`(중국어) / `en`(영어) / `ko`(한국어)이며, 적지 않으면 `zh`로 처리합니다. 대사 길이, 음성 인식, 자막 글꼴과 줄바꿈, 프롬프트 속 고정 문장이 모두 이 값을 따릅니다. 언어별 매개변수는 `scripts/lang/langs.json`에 있습니다.
- `speechRate`(선택): 이 작품 대사의 말 속도. 중국어와 한국어는 초당 글자(음절) 수, 영어는 초당 단어 수입니다. 적지 않으면 `langs.json`의 값을 씁니다: 중국어 3자/초는 실측값이고, 영어와 한국어는 시험 컷으로 잰 값입니다. `workflow.md` 「이야기 언어」를 보세요.
- `style`: 화풍 접두어. 모든 설정화와 콘티 그림의 프롬프트 앞에 이 문장을 붙입니다. 적지 않으면 경고가 나오고, 전체 화풍이 통일되지 않습니다.
- `targetSeconds`: 한 화의 목표 길이. 숫자 하나나 구간으로 적을 수 있습니다.
- `images.provider`: 이미지 생성 방식. `manual`(기본값) / `cmd` / `codex`. `adapters/image.md`를 보세요.
- `video.target`: 영상 프롬프트를 어느 도구에 맞춰 쓸지. `grok` / `generic` / 직접 쓴 `scripts/targets/<이름>.mjs`. `durations`를 적지 않으면 target에 들어 있는 길이 단계를 씁니다.
- `alias`: 외모 문구. 영상 도구는 인물 이름을 모르므로, 프롬프트 속 인물 이름을 이 문구로 바꿉니다. `en`은 영어 문장에, 이야기 언어 항목(`zh` / `ko`)은 이야기 언어 문장에 쓰입니다. 영어 이야기라면 `en`만 적습니다. 적지 않으면 원래 이름을 씁니다.
- `trait`(선택): 인물의 특이한 신체 특징. 예를 들어 먼 눈, 흉터, 저는 다리. 인물이 정면으로 화면에 나올 때, 프롬프트에 영어와 이야기 언어로 「처음부터 끝까지 유지」를 한 번씩 적습니다. 키는 `alias`와 같습니다. 이야기 언어 키와 `en`을 쓰세요. 이야기 언어 키가 없으면 이 특징은 프롬프트에 들어가지 않으며, `validate.mjs`가 알려 줍니다. 첫 프레임만으로는 지켜지지 않고, 영상 도구가 이 특징을 「고쳐」 버립니다(Grok 실측).
- `ambient`: 장소의 환경 움직임. 키는 대본의 빛(`light`)이고, `*`는 기본값입니다.
- `aspect`(선택): 완성본의 화면비. `너비:높이`로 쓰고, 쓰지 않으면 `16:9`입니다. 세로 숏드라마는 `9:16`으로 씁니다. 콘티 그림, 영상 프롬프트, 이야기 미리보기, 편집, 자막이 모두 이 값을 따릅니다. 캔버스의 긴 변은 1920이라 16:9는 1920×1080, 9:16은 1080×1920입니다. 설정화는 참고 이미지라 완성본에 들어가지 않으므로 항상 16:9입니다.
- `cutTail`(선택, 초): 편집할 때 대사가 있는 숏은 대사가 끝나고 이만큼 더 두고 자릅니다. 쓰지 않으면 대사 숏은 적어도 콘티 길이만큼 남깁니다. 콘티 길이는 영상 도구의 6/10초 단위를 따라 길게 잡혀 있어서 대사 뒤에 인물이 1~2초 멀뚱히 서 있게 되고, 구간 끝에서 특히 늘어집니다. `0.6` 안팎이면 대사가 끝나자마자 다음 숏으로 넘어갑니다. 반응을 남겨야 하는 숏은 `fix.json`에서 따로 길이를 정합니다.
- `sheet`: 설정화 프롬프트. 인물은 얼굴 전체, 머리 모양, 의상, 나이를 적습니다. 젊은 여성은 「성인」임을 밝혀야 합니다. 그렇지 않으면 미성년자로 판정될 수 있습니다. `prompt-rules.md`를 보세요.

## script.json

```json
{
  "episodes": [
    {
      "ep": 1,
      "targetSeconds": 120,
      "scenes": [
        {
          "scene": "S01",
          "light": "짙은 안개 낀 이른 아침",
          "cast": ["C01", "C03"],
          "props": ["P01"],
          "beats": [
            { "act": "그녀가 낡은 가죽 트렁크를 안고 안개 낀 강둑을 달린다." },
            { "who": "C03", "say": "上船喽，过河的抓紧。", "tone": "목청을 높여, 서두르지도 느긋하지도 않게" },
            { "who": "C01", "say": "这一路，总算到了。", "tone": "아주 조용히", "inner": true }
          ]
        }
      ]
    }
  ]
}
```

비트(beat)는 세 종류뿐입니다:

| 종류 | 쓰는 법 | 기본 길이 |
|---|---|---|
| 동작 | `{ "act": "..." }` | 2.5초 |
| 대사 | `{ "who", "say", "tone" }` | 글자 수 ÷ 말 속도 + 1초(말 속도는 `speechRate` 참고. 영어는 단어 수) |
| 속마음 / 보이스오버 | 대사에 `"inner": true`를 더함 | 위와 같음 |

- 비트는 장 안에서 1부터 번호를 매기고, 콘티는 이 번호로 비트를 가리킵니다.
- `tone`에는 말투만 쓰고 동작은 쓰지 않습니다. 「땀을 훔쳤다」 같은 동작을 `tone`에 쓰면 영상 도구가 그것을 대사로 읽어 버립니다(Grok 실측). 동작은 따로 `act` 비트 하나로 씁니다.
- `say`에는 줄표를 쓰지 않고 쉼표를 씁니다. 중국어의 줄표는 「一」로 읽혀서 `validate.mjs`가 오류를 냅니다. 영어와 한국어는 알림만 주고, 프롬프트에서는 자동으로 쉼표 멈춤으로 바뀝니다.

## storyboard.json

```json
{
  "episodes": [
    {
      "ep": 1,
      "segments": [
        {
          "id": "E01-01",
          "scene": 1,
          "blocking": "이 세그먼트가 시작될 때 각 인물의 위치와 자세, 소품을 누가 들고 있는지",
          "sound": "환경음",
          "cuts": [
            {
              "beats": [1, 2],
              "seconds": 6,
              "size": "medium",
              "camera": "Push In",
              "move": { "from": "전신 미디엄숏", "to": "가슴 위 클로즈업", "stop": "그녀가 그 말을 마칠", "speed": "천천히, 안정적으로" },
              "chars": ["C01"],
              "props": ["P01"],
              "frame": "첫 프레임 화면 묘사: 숏 크기, 누가 어디에, 자세, 방향, 소품 상태, 빛",
              "action": "이 컷에서 일어나는 동작. 영상 모델에게 주는 글",
              "aim": "카메라가 향하는 인물",
              "angle": "눈높이 / 약간 로우 앵글 / 하이 앵글",
              "lens": "50mm 표준, 약간 얕은 심도",
              "eyeline": "인물이 바라보는 곳",
              "focus": "초점을 고정하는 곳",
              "limits": ["콘티에서 추론할 수 없어 손으로 적는 제약"]
            }
          ]
        }
      ]
    }
  ]
}
```

- 세그먼트(segment): 같은 장소에서 이어지는 한 덩어리의 장면. 번호는 `E화-세그먼트`입니다. `scene`은 이 세그먼트가 이번 화 대본의 몇 번째 장인지를 1부터 세어 적습니다.
- 컷(cut): 숏 하나, 즉 영상 생성 한 번. `beats`는 `[시작, 끝]`이며 이 장의 비트 번호를 가리킵니다.
- `seconds`: 콘티상의 길이. 영상은 6초나 10초로 생성합니다. 대사가 콘티보다 길면 편집에서 대사에 맞춰 충분히 남깁니다.
- `size`: 숏 크기. 아래 일곱 값 중 하나입니다.

  | 값 | 화면을 어디서 자르는가 | 화면에 꼭 남길 것 | 쓰는 곳 |
  |---|---|---|---|
  | `extreme-wide` | 장소 전체. 사람은 점이거나 없음 | 어디인지 알아볼 수 있음 | 오프닝, 장면 전환, 시간 경과 |
  | `wide` | 사람과 넓은 주변 | 사람이 이 장소의 어디에, 누구와 얼마나 떨어져 있는지 | 위치 관계 |
  | `full` | 머리부터 발끝까지, 움직이는 방향 앞에 여백 | 한 동작의 처음부터 끝까지 | 달리기, 걷기, 배에 오르내리기. 얼굴 식별이나 대사가 없을 때 |
  | `medium` | 허리 위 | 두 손과 손에 든 소품, 서로 바라보는 두 사람 | 대화, 물건 건네기, 사람 사이의 교류 |
  | `medium-close` | 가슴 위. 손은 가슴까지 들어 올릴 때만 화면에 | 얼굴과 시선 방향 | 말하는 사람, 듣는 사람의 반응 |
  | `close` | 이마부터 턱까지 얼굴 하나, 또는 소품 하나가 화면을 채움 | 감정을 싣는 그 한 가지: 눈빛, 입꼬리, 꽉 쥔 것 | 감정이 가장 무거운 순간 |
  | `extreme-close` | 눈 하나, 손가락 하나, 잠금쇠 하나 | 그 한 부분. 비교할 두 가지가 모두 읽혀야 함 | 단서, 증거, 작은 동작. 대사 없음 |
- `camera`: `Static Shot`, `Push In`, `Pull Out`, `Pan`, `Tilt`, `Rack Focus`, `Tracking Shot`, `Handheld`, `Crane`, `POV`.
- `move`: 카메라 움직임의 세부 사항. `prompt-rules.md`의 「카메라 움직임」 절을 보세요. 필드는 `from`, `to`, `stop`, `dir`, `speed`, `target`, `distance`, `level`, `who`, `height`, `then`입니다.
- `sheets`(선택): 이 컷에 추가로 붙일 설정화 번호. 장소 설정화는 이 장의 것만 자동으로 붙으니, 다른 설정화의 것이 화면에 나오면 여기에 씁니다. 예: 부두에서 나룻배가 보이면 `["S04"]`. 번호의 첫 글자로 인물, 장소, 소품을 구분하고, 자동으로 붙는 이미지 뒤에 붙습니다. `project.json`의 인물, 장소, 소품 항목에도 `sheets`를 쓸 수 있으며, 그 설정화를 그릴 때 붙습니다. 예: 나룻배 외관이 선실과 맞도록.
- `place`(선택): 이 컷을 찍는 곳이 이 장의 장소와 다를 때 씁니다. `{ "name": "강가 흙길", "ambient": "양옆의 마른 갈대가 흔들리고……" }`. 프롬프트의 장소 이름과 환경 움직임이 이것으로 바뀌며, `ambient`를 빼면 환경 움직임을 넣지 않습니다. `place`를 쓰면 그림을 그릴 때 이 장의 장소 설정화를 자동으로 붙이지 않으니, 필요한 설정화는 `sheets`에 적습니다.
- `only`(선택): 손이 아닌 신체 일부(발, 주머니, 옷자락)의 클로즈업에서 화면에 무엇만 보이는지 적습니다. `{ "ko": "앉은 사람의 외투 주머니, 외투 자락과 허벅지", "en": "the coat pocket, coat hem and thigh of the seated man" }`처럼 이야기 언어 키와 `en`을 씁니다. 없으면 생성기가 「화면에는 손, 소맷부리, 소품만」으로 쓰고, 주머니를 찍으면 손이 밖으로 나옵니다.
- `frame`과 `action`에는 인물 이름을 그대로 써도 됩니다. 프롬프트를 만들 때 `alias`로 바뀝니다.
- `insert`(선택): 삽입 숏. 이미 있는 소재(화면 녹화, 스크린샷)를 쓰고, 이미지와 영상을 만들지 않습니다. 작품 폴더 기준 상대 경로나 `{ "file": "inserts/list.mp4", "fit": "blur" }`로 씁니다. `fit`은 소재 비율이 화면비와 다를 때 놓는 방법입니다: `blur`(기본, 원래 크기로 가운데 두고 뒤에 확대·흐림 처리한 같은 화면을 깝니다) / `crop`(확대해 꽉 채움) / `pad`(원래 크기로 가운데, 빈 곳은 검은 띠). 삽입 숏에는 `beats`, `seconds`(2–30초), `insert`만 쓰고 숏 크기, 카메라, 인물은 쓰지 않습니다. 소리가 없으므로 덮는 비트에 대사가 있으면 안 되고, 편집에서 무음을 깝니다. 소재가 아직 없으면 미리보기는 글자 카드를 보여 주고 편집은 이 구간을 잇지 않습니다.
- `screen`(선택): 화면 합성. 숏 속 컴퓨터나 TV 화면을 편집에서 소재로 바꿉니다. `{ "file": "inserts/confirm.mp4", "corners": [[x, y], [x, y], [x, y], [x, y]] }`. `corners`는 화면의 네 모서리로, 왼쪽 위, 오른쪽 위, 오른쪽 아래, 왼쪽 아래 순서이며 단위는 완성본 캔버스 픽셀입니다. 숏이 나온 뒤 재서 씁니다. 없으면 `validate.mjs`는 알림만 하고 편집은 이 구간을 잇지 않습니다. 첫 프레임에서 화면을 꺼진 단색으로 그리고 카메라는 `Static Shot`으로 해야 모서리가 맞습니다. 손에 든 휴대폰이나 태블릿은 계속 움직이므로 화면 합성 대신 삽입 숏을 씁니다.
- `title`(선택): 화면 글자. 숏폼 드라마에서 인물이 처음 나올 때 띄우는 이름 카드 같은 것입니다. 편집에서 투명 레이어로 그려 이 컷 위에 페이드 인·아웃으로 얹고, 서사 미리보기에도 그립니다. 글자는 영상 모델을 거치지 않으므로 그대로 나옵니다. 문자열 `"조금보"`, 또는 `{ "text": "조금보", "sub": "맞은편 가게 사장", "at": 0.3, "seconds": 2.5, "pos": "left", "y": 0.62 }`로 씁니다. `text`는 큰 글자(세로 화면은 6자, 가로 화면은 10자 안팎을 권장, 넘치면 글자가 작아집니다), `sub`는 아래 작은 라벨, `at`과 `seconds`는 이 컷의 몇 초부터 몇 초 동안인지(기본 0.3, 2.5), `pos`는 `left` / `center` / `right`, `y`는 화면 높이 대비 글자 중심선 위치(기본 0.62, 아래 자막을 피함)입니다. 글꼴은 환경 변수 `TITLE_FONT`로 지정하고, 없으면 자막 글꼴을 씁니다. 편집이 이 컷을 줄이면 화면 글자도 함께 일찍 끝납니다.

## 번호 규칙

| 대상 | 번호 | 예 |
|---|---|---|
| 인물 / 장소 / 소품 | `C` / `S` / `P` + 두 자리 숫자 | `C03`, `S01`, `P02` |
| 세그먼트 | `E화-세그먼트` | `E03-06` |
| 컷 | `세그먼트/s컷` | `E03-06/s2` |
| 내려받은 영상 파일 | 파일 이름에 `세그먼트-s컷` 포함 | `E03-06-s2.mp4`, `grok-E03-06-s2.mp4` |
| 검수할 때 부르는 번호 | `세그먼트-컷` | `06-2` |
