# 다른 영상 도구로 영상 생성하기

> 미실측. dramazing은 Grok 웹에서만 작품 한 편을 끝까지 만들어 봤습니다(`video-grok.md` 참고). 아래는 「첫 프레임 + 텍스트 → 영상」 종류 도구의 공통점을 바탕으로 썼습니다. 도구를 바꾸면 1화에서 시험 컷을 몇 개 더 생성하고, 실측 결과를 이 문서에 보태 주세요.

## 도구가 갖춰야 할 조건

| 조건 | 이유 |
|---|---|
| 이미지 한 장을 첫 프레임으로 쓸 수 있다 | 인물, 의상, 장소의 일관성은 전적으로 첫 프레임에 달려 있다 |
| 이야기 언어로 대사를 말하고 입 모양이 맞는다 | 숏드라마는 대사로 이야기를 끌고 간다. 소리 없는 화면만 만드는 도구는 따로 더빙해야 한다 |
| 5~10초 영상을 만들 수 있다 | 컷 하나는 보통 2~8초이고, 편집할 여유를 남긴다 |
| 16:9, 1080p 안팎으로 만들 수 있다 | 첫 프레임, 완성본과 맞춘다 |

Kling, Jimeng, Veo, Runway, Hailuo 같은 도구는 대부분 앞의 세 조건 가운데 대부분을 갖추고 있습니다. 구체적인 것은 현재 버전을 기준으로 확인하세요.

## 프롬프트

```bash
node scripts/video-prompts.mjs --work $W --ep 1 --target generic
```

- `video/shots.json`: 컷마다의 설명. 도구와 상관없습니다.
- `video/prompts.json`: `generic` 작성법. 줄을 나눠 출력하며, 길이 단계는 5 / 10초입니다.

도구의 길이 단계가 다르면 `project.json`에 적습니다:

```json
"video": { "target": "generic", "durations": [5, 10] }
```

## 특정 도구 전용 작성법 쓰기

어떤 도구만의 특성을 실측으로 알아낸 뒤(예: 영어를 더 잘 따른다, 특정한 머리말이 필요하다, 입력창에서 줄을 바꿀 수 없다), `scripts/targets/grok.mjs`를 본떠 `scripts/targets/<도구 이름>.mjs`를 씁니다:

```js
import { body, FILM_HEAD } from './_common.mjs';
export default {
  durations: [5, 10],             // 이 도구의 길이 단계, 오름차순
  render(shot, project, ctx) {    // shot은 shots.json의 항목 하나. ctx에는 이야기 언어의 고정 문장과 언어 이름이 들어 있다
    return [FILM_HEAD, ...body(shot, ctx), '...'].join('\n');
  },
};
```

그러면 `--target <도구 이름>`으로 쓸 수 있습니다. `body()`는 이미 `prompt-rules.md`에 따라 동작, 시선, 카메라 움직임, 대사, 제약을 써 두었으므로, 보통은 머리말, 맺음말, 이어 붙이는 방식만 바꾸면 됩니다.

## 영상 생성과 수집

1. 첫 프레임 `frames/<세그먼트 번호>/f<N>.png`를 올리고, `prompts.json`에서 해당 항목의 `prompt`를 붙여 넣고, 길이는 `seconds`로 고릅니다.
2. 내려받은 파일 이름에 컷 번호를 넣습니다. 예: `E01-03-s1.mp4`.
3. `bash scripts/ingest.sh $W`로 `video/E01-03/s1.mp4`에 수집합니다.

편집 스크립트는 어떤 해상도든 1920×1080으로 맞춰 크기를 조정하고 잘라 냅니다.

## 실측해야 할 것

도구를 바꾸면 시험 컷으로 최소한 다음 항목을 시험하고, 결과를 이 문서에 다시 적습니다:

- 대사: 제대로 읽는지, 말투 안내를 대사로 읽어 버리지 않는지.
- 입 모양: 말하는 그 사람이 입을 움직이는지.
- 첫 프레임: 얼굴, 의상, 인물의 특이한 신체 특징(먼 눈, 흉터)이 유지되는지.
- 카메라 움직임: 푸시 인, 풀 아웃, 패닝을 하나씩 생성해 제대로 되는지, 멈춰야 할 곳에서 멈추는지.
- 심사: 젊은 여성 클로즈업이 걸리는지.
- 사용량: 5초짜리 하나, 10초짜리 하나에 각각 얼마나 드는지.
