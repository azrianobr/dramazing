# 出一集的流程

一集从分镜到成片分 12 步。每一步只规定输入和输出（放在作品目录的哪里），用什么工具都行：

| 环节 | 输入 → 输出 | 实测过的工具 | 换别的工具 |
|---|---|---|---|
| 写剧本、分镜 | 原文 → `script.json`、`storyboard.json` | Claude Code | 任何能读 SKILL.md 的 AI 助手，或人工写 |
| 出图 | `tasks.json` → `sheets/*.png`、`frames/*/f*.png` | Codex CLI | 见 `adapters/image.md`：手动用任何出图工具，或接你自己的命令行 |
| 出片 | 首帧 + `prompts.json` → `video/E01-03/s1.mp4` | Grok 网页 | 见 `adapters/video-other.md`：可灵、即梦、Veo、Runway 等 |
| 剪辑、字幕 | 镜头 → 成片 | ffmpeg + whisper.cpp（开源） | 一般不用换 |

参考数据：《渡口》第 4 到第 6 集用 Codex + Grok，每集约 2 到 3 小时，用掉 Grok 周额度的 6% 到 12%。

下面的命令都在 skill 根目录运行，`W` 是作品目录，`EP` 是集数：

```bash
W=works/我的作品; EP=1
```

## 两道关口

整个流程里有两处必须停下来，等用户看过点头才往下走：

1. **叙事预览**（第 4 步）：用分镜图拼一版粗剪，确认故事看得懂。只看画质不够，画面没问题、故事没人看懂的情况真实发生过。有的用户看静态图说不出问题在哪（《渡口》第 1 集重制时就是这样）；这时问一句，跳过预览，改为对着试探镜头和剪好的段落审。
2. **试探镜头**（第 7 步）：先出一条有人脸、有台词的镜头，确认画质、口型和声音。每集都做。

## 演员库

做多了容易只剩几张脸：换了衣服、换了作品名，观众看到的还是同一个人。所以在 `works/_演员库/` 放一份跨作品的演员库，每部从里面选角，不在作品里临时造脸。

- **结构是「演员 → 角色」**。`cast.json` 里每个演员有固定的艺名、一张定妆照（`sheets/<编号>.png`）、一段固定声音（`voices/<编号>.wav`），下面列出他在各部作品里演的角色名。同一个演员可以演张三也可以演李四，名字和衣服跟着作品变，脸和声音不变。空的模板在 `templates/<语言>/cast.json`。
- **定妆照**：浅色纯背景 16:9，左边半身正面，右上正侧背三面全身，右下笑、怒、哭、木四个表情。提示词里不写「漂亮」「帅气」这类词，每人写 3–4 个一眼能认出的硬特征（脸型、单双眼皮、肤色、痣、疤、牙缝、发型），并把这几个特征同时写进 `长相`。只有主角脸写「像电视剧演员一样好看，不是网红脸」。新脸出完先拼一张总览，和库里所有人放在一起看，有两张像同一个人就重出。
- **换装测试**：新演员进库前，挂定妆照当参考图 1，换一身完全不同的衣服出一张，看脸和身材还是不是本人。认不出就重出。
- **声音**：新演员用 `dub.py say --model design` 按嗓音描述出一段 6–13 秒样音，存进 `voices/`。以后这个人的台词一律用 `--model clone` 克隆这段样音。演员以前在别处说过话，就从旧片里截他单独说话的片段当样音。
- **选角**：每部写分镜前，从库里按戏路和年龄挑人。作品里人物设定图的提示词写「脸和发型照参考图 1 里的人」，挂上他的定妆照，再把 `长相` 那句硬特征写进去。选完把角色追加进 `cast.json`。
- **服装照词典写**（`docs/refs/AI短剧服装款式词典.md`）：按部位（领、袖、上衣、外套、下装、鞋、配饰、发型）逐件写，每件写「具体色名 + 面料 + 款式名」，款式名后面补一句白话外观，例如「德比鞋（系带的休闲皮鞋）」，模型不一定认识冷门款式名。用新旧写身份（洗旧、起球、熨烫平整），要演出年纪时查「年龄感、身份感速查」。只写看得见的衣服，不写「医院」「学校」这类类别词，不写品牌和 Logo。
- **女鞋按「种类 → 跟高 → 鞋头 → 装饰和材质」的顺序写**（`docs/refs/AI短剧女鞋高跟鞋款式.md`），例如「象牙白小羊皮尖头后空鞋，6cm 细跟」。浅口鞋有后跟包脚，穆勒鞋后跟是空的，别混写。鞋只在入画的镜头和设定图的全身视图里写，近景不写。要让鞋出现，就安排全身或坐姿露鞋的镜头，例如下车先落脚、走进门；不拍长时间停在脚上的特写。
- **袜子和丝袜按「类型 → 厚度（D 数）→ 颜色 → 哑光或微光 → 花纹」写**（`docs/refs/AI短剧袜子丝袜款式.md` ①–⑦），例如「20D 肤色哑光连裤袜」。日常戏一定写「哑光」，只写「丝袜」常被画成一层油亮反光。袜子的颜色和透明度写进设定卡的鞋袜一栏，每张首帧原样重复。冬天写「加绒」，并配大衣和靴子。日常戏用全身或中景，不拍腿部特写。男角穿皮鞋配黑色商务袜，穿黑布鞋配白棉袜。长筒袜、吊带袜、渔网、亮面、烫钻、白丝这些款式（⑧ A–E）和日常款一样照常用，写法顺序是「款式 → D 数 → 颜色 → 光泽 → 装饰 → 袜口」，用在夜店、舞厅、约会、心机女配这类戏。尺度看的是动作和姿势，不看款式：动作照常按剧情写，不用 ⑧F 的擦边镜头和姿势。白丝、过膝袜不配校服、双马尾和显小的打扮，人物写明成年年龄。
- **每个角色先写一张服装设定卡**（`docs/refs/AI短剧服装造型指南.md` 3.1）：主色、辅色、点缀色各一个具体色名，每件的面料和版型，内搭到外套的层次，鞋的新旧，配饰最多 3 件并写清哪只手哪一侧，生活痕迹（坐压褶皱、袖口磨白），禁用项。卡里的服装那段定稿后，设定图和每张首帧都原样粘贴，一个字不改，全剧色名不换说法。同场对立的两人在色调冷暖或明暗、面料贵贱上拉开。写质感时写「布料顺重力垂坠、哑光，皮肤柔光，只有金属有硬高光」，不写「高清」「精致」。挂几张参考图就写清每张管什么：定妆照只管脸和发型，设定图管衣服的版型和配色，场景图只管空间。
- **选角后先只出人物设定图，用户点头再出场景、道具图和首帧。** 《换号》换衣、换身形、换演员三轮，13 张首帧跟着改了三遍。设定图是最便宜的一步，人物定了再往下走。
- **服装默认往开放一档设计，写到时尚大片的细度。** 用户 11-01（《电视声》）：「衣服都太保守了，在规则之内开放一点，观众也喜欢看」。合场景的吊带、短裙短裤、露肩、光腿、修身都可以用，衣服穿着完整。服装设定卡写到面料（欧根纱、缎面、细罗纹）、剪裁结构（细肩带和露肩薄纱交叠、立体剪裁、荷叶裙摆、细滚边）、细节装饰、发饰和首饰；只写「吊带背心、短裤」出来就是普通家居服。
- **女主加一张造型大片。** 设定图定下后，每部给女主出一张全身时尚照：自然站姿、暖色侧逆光勾出发丝和衣料轮廓、85mm 人像镜头、背景适度虚化，可以当封面和宣传图。用户给的时尚大片提示词挂演员定妆照，OpenAI 一次通过（`works/电视声/_logs/test-fashion.txt`）。
- **首帧给脸一道柔光，暗场景也一样。** 写「人物面部明亮柔和，侧逆光勾出发丝和衣服的轮廓」，不让人脸跟着环境一起暗。
- **居家暗场景里，坐姿写自然，不写盘腿、抱膝、蜷缩。** 《电视声》f1 深夜沙发、吊带短裤、盘腿抱膝，OpenAI 在输出阶段判 sexual；同样的衣服，时尚大片里的站姿一次通过。尺度由姿势和语境决定，衣服本身不是问题。被拒照规则用 Grok 兜底，再用 OpenAI `fix` 把脸改回演员的脸。
- **OpenAI 改图连续断线（`EOF`、500）时，用 Grok 图片编辑兜底。** 《电视声》f5 连续 4 次 EOF。Grok Imagine 切到「图片」、选「质量 2.0」，上传原图，写英文的「只改这一处，其余不变」，一次出图。下载的是 1008×1792，放大到 1152×2048 再用。
- **衣服以外的布料别和某人的衣服同色同质。** 《电视声》沙发上的燕麦色针织毯和小琪的开衫一样，盖在小雯腿上，用户说「她把小琪的衣服盖在腿上了」。毯子挪到沙发靠背上不盖人，或者换一个和所有衣服都不同的颜色。
- **给演员换衣服时，照抄演员库定妆照的身形描述，不写「不暴露」「不夸张」「腰间有横褶」这类词。** 《换号》换修身针织裙后用户说腰腿变粗：这类词会让模型往保守、敦实画。修身衣服最挑身形；改字、挂审美尺度参考图、局部收窄都压不下去时，直接换身形更纤细的演员。
- **场景照词典按清单写**（`docs/refs/AI短剧场景款式词典.md`）：不写「温馨」「高级」这类形容词，按 5 格填：① 年代、地区、阶层；② 什么房间；③ 5–8 样具体东西（墙、地、家具、灯、杂物，杂物最能让画面像有人住）；④ 时间和光从哪来；⑤ 不是什么（不是样板间、没有可读文字、不要西式装修）。家具写新旧（掉漆、发黄、用了很多年）。门牌、招牌、横幅不写具体的字，写「没有可读文字」。现成的 34 套组合在第 9 部分，都没实测过，用前先出一张空场景图看效果。场景设定图里这段定稿后，每张首帧原样粘贴。
- **场景一致性**（`docs/refs/AI短剧场景一致性指南.md`）：每个场景编号 ENV-01、ENV-02，写一段场景块（布局、门窗、光的方向和色温、桌上道具的数量和位置），这段每张首帧和设定图都原样粘贴。场景设定图用四分之三侧面的广角，把所有出镜位置都画进去；正面图一换机位就只能瞎猜。要拍反打时，从同一张设定图派生反打角度的参考图，同天同光，结构互相矛盾的参考图宁可不挂。每切都写死谁在画左谁在画右、视线朝哪边、前景肩膀是谁的，不只写「遵守轴线」。道具写数量和状态，要变就写从第几切起怎么变。所有首帧都从确认过的原始设定图或全景派生，不拿上一张派生图再派生，免得越传越漂。场景隔几切再出现，或反打看到另一半空间时，把之前同场景的截图一起挂上。
- **账号规则写在 `cast.json` 的 `规则` 里**，选角时逐条核，比如「每部至少一个女性用主角脸」（演员的 `主角脸` 为 true）。
- **新演员的定妆照从零出，提示词按六节写**（`writing.md`「人物设定图的提示词分六节写」），不挂参考图。在旧图上改身材（拉长腿、收细腰）会顾此失彼：《改口费》前试了五轮，腿拉得不像真人，用户都没通过；从零出一次就过。写身材时只写一句整体印象，不写头身比、腿长占比这类数字。
- **角色设定图跟着每部的角色出，不是演员档案。** 竖版总表（主视觉、档案表、面部发型特征、全身四视图、体型参考、六个表情、细节特写），「职业」填这个角色在剧里的职业。分开出再拼：每块单独出图、都挂定妆照锁脸，细节特写每格单独出一张、主体居中；档案表和特征表的字由代码排，不让模型写字（整张直出时「臀宽」「鞋码」常写错）。

## 步骤

### 1. 写分镜

按 `writing.md` 写这一集的 `script.json` 和 `storyboard.json`（把 `ep: N` 追加进去，前几集保留）。写完校验：

```bash
node scripts/validate.mjs --work $W --ep $EP
```

- **怀旧、年代戏要有一句不懂年代也能看懂的落点。** 《地瓜干》按剧本做完，用户说「这一整部在表达什么我都没明白」：故事靠观众懂「1975 年白面馍金贵」才成立，又没有落点。补了 2025 年老两口的结尾：满桌好菜，她照样掰馒头分他一半，老头说「五十年了，还是一人一半」，才立住。选到靠年代细节打动人的剧本时，写分镜前先问一句「不懂背景的观众看完能明白讲什么吗」。不能，就接一个「现在」的场景，同一对人，用一句台词点明。
- **新场景的节拍号从 1 数，新角色登记进 `project.json` 的 `characters`。** 节拍号写成全局号，字幕会丢；角色没登记，限制条件里会出现 undefined。

### 2. 出图

```bash
node scripts/frames.mjs plan  --work $W --eps $EP --force      # 建任务单（已有的图记为完成，不会重画）
node scripts/frames.mjs batch --work $W --only "E0$EP-01/"     # 先只出第 1 段
```

先看第 1 段：服装、站位、场景和上一集接不接得上。没问题再出全部：

```bash
node scripts/frames.mjs batch --work $W
```

- 提示「N 张参考图还没出」时，再跑一遍。
- 重画已有的图加 `--redo`；只改一处用 `fix`：`frames.mjs fix --work $W --target frames/E01-03/f2.png --prompt <文件>`。原图自动当参考图 1，提示词只写要改的那一处，其余保持不变的句子由 `fix` 补上。
- 位置的小修正（门把手高低、道具挪几十像素）直接改像素，不走 `fix`。`fix` 改位置容易过头：《那个女生》02-5 首帧门把手太低，`fix` 两次，一次只挪一点，一次挪得偏高；用 PIL 把把手那一块剪下来往上贴到正常高度，一次对。改之前先把旧图拷到 `_bak/versions/`。
- 挑机位（可选）：设定图或首帧出好后，`frames.mjs grid --work $W --from frames/E01-03/f1.png --name 楼道` 出一张 16:9 宫格图，放在 `_handoff/grid/楼道.png`。行是机位高度（默认平视、仰拍、俯拍），列是景别（默认远景、中景、特写、大特写），可用 `--rows`、`--cols` 换。挑好后改分镜的 `angle` 和 `size`，再重出那几切；想让出图照着某一格的角度画，用 `frames.mjs grid --work $W --name 楼道 --crop 2,3` 切出第 2 行第 3 列，当 `fix --ref` 或手动出图的参考。每格只有约 418×314，只用来挑角度，不当首帧；不改任务单。
- 出图方式由 `--provider` 或 `project.json` 的 `images.provider` 决定：`manual`（默认，导出说明后用任何工具出图，再用 `place` 放回）、`cmd`（接你自己的命令行）、`codex`、`openai`（OpenAI 图像接口）。见 `adapters/image.md`。

### 3. 看图

每张都看完整画面，不只看人脸。常见问题：

- 多出一个不该有的人（前景一个看不清的肩膀也算）。
- 人物显得稚气。
- 背景不符合年代和地域。
- 道具状态和 `blocking` 不一致。
- 手和脚：数每个人有几只手，左右脚、左右手对不对。坐姿最容易出错（《老地方》E01-01/f7 三只手，定稿后才发现）。
- 定妆细节：对照设定图核指甲油、戒指、首饰。首帧会漏，视频照着演（《老地方》20 张里 3 张指甲画成裸色，返工 4 次）。

### 4. 叙事预览（关口 1）

```bash
python3 scripts/preview.py --work $W --ep $EP
```

输出 `video/E0N.preview.mp4`：每切的分镜图按秒数停留，底部叠上台词，左上角是镜头编号。给用户看，确认故事看得懂。

用户说看静态图判断不了，就不再出预览：多出一两条试探镜头，把站位、地点这类问题放到会动的片子里看。

### 5. 生成提示词

```bash
node scripts/video-prompts.mjs --work $W --ep $EP --target grok   # 或 generic，或你自己写的 targets/<工具>.mjs
```

写两份文件，同时打印预检警告：

- `video/shots.json`：镜头描述（动作、视线、运镜、台词、限制），和用哪个视频工具无关。
- `video/prompts.json`：按目标工具渲染好的提示词和时长档位。

已有的条目不覆盖，手改过的提示词可以放心重跑。换工具时加 `--force` 重新渲染。

### 6. 逐条过提示词

对照首帧逐条看：

- 动作方向和首帧对不对得上。
- 谁出镜、谁说话。
- 心声镜头里，说话人是不是正脸、嘴闭着。
- 运镜有没有写终点。

规则见 `prompt-rules.md`。

### 7. 试探镜头（关口 2）

挑一条有人脸、有台词的镜头先出，最好同时测这一集的新东西：新人物、新道具或新运镜。给用户看，过了再批量。

### 8. 出片

在视频工具里逐条出片：上传首帧，粘贴 `prompts.json` 里这一条的 `prompt`，时长选 `seconds`。下载的文件名里带上镜头号，比如 `E01-03-s1.mp4`（前面加工具名也行）。

- Grok：见 `adapters/video-grok.md`（实测过）。
- 其他工具：见 `adapters/video-other.md`（未实测，第一集先多出几条试探镜头）。

出片前、批量出完、返工后，各记一次用量（额度百分比、积分或花费），写进 `_logs/usage.tsv`。

### 9. 收片

```bash
bash scripts/ingest.sh $W            # 默认从 ~/Downloads 收；别的目录写在第二个参数
```

### 10. 剪辑、审片

```bash
python3 scripts/cut.py --work $W --ep $EP                                 # 剪成段
node scripts/assemble.mjs --work $W --ep $EP --loudnorm --align --no-burn # 拼整集，对齐字幕
python3 scripts/review.py --work $W --ep $EP                              # 审片版：左上角带镜头编号
```

- `cut.py` 用 whisper 测台词说完的时间，至少留到台词说完。
- 手工剪点写进 `video/fix.json`：`{"E01-06": {"fix": {"1": 4.0}, "skip": [2], "in": {"3": 1.25}, "speed": {"4": 1.6}, "subs": {"台词原文": [起, 止]}}}`（`subs` 见下面「手改的字幕时间」）。`fix` 的镜头不会被压缩；`fix` 是加速后的成片秒数，这一切照样按 `--rate` 自动加速，要固定系数就在 `speed` 里写。`in` 是从原片第几秒开始取：动作来得比提示词写的晚（比如灯晚了 1 秒才灭），就从后面取，不用重出。
- 抽帧检查一律看完整画面，不裁到人脸。
- 用户按编号（如 `06-2`）提意见。返工先看有没有备用的第二条，没有再重出，然后回到第 9 步。
- **中途要加镜头**（看片后要补交代、补节奏）：先把新镜头写进 `storyboard.json`，再用 `renumber.mjs` 把后面的镜头号整体后移，不要手工改名。它会一起改首帧、原片、`fix.json`、`prompts.json`、`shots.json` 的编号；漏改 `prompts.json`、`shots.json` 时，`cut.py` 会按旧编号认台词，剪出来的长度不对（《真的》）。改完照它的提示重建任务单、补提示词。要去掉一个镜头，在 `fix.json` 的 `skip` 里写它的号，不用改号。

  ```bash
  node scripts/renumber.mjs --work $W --seg E01-03 --insert 2 --count 2 --dry   # 先看要改哪些
  node scripts/renumber.mjs --work $W --seg E01-03 --insert 2 --count 2         # 原第 2 切起顺延 2 个号
  ```
- **烧的字幕落在不动的深色区域（衣服、墙），用干净帧盖住那一块。** 逐帧找出字幕出现、消失的时间和范围，取开口前的一帧裁出那块，用 `overlay` 只在那几帧盖上，原片存进 `_bak`。口型保留，比盖成对方的反应好（《赊账》s5「挺好」两次都烧在胸口毛衣上，220×140 的一块盖 0.2–0.95 秒，看不出来）。字幕压在脸上或会动的地方，再按下一条处理。
- **单人短台词镜头反复烧字幕，就只用它的声音。** 换写法重出两三次还烧，就把这一切的画面用 `cover` 盖成对方的反应镜头，声音照用。打电话的戏常这么剪：观众听着这一方说，看着另一方的反应（《跟谁吃的》02-3「我都快到家了」三次都烧字幕，盖成他皱眉的反应）。盖画面的素材逐帧看表情，镜头后半段常带笑。
- **手改的字幕时间存进 `fix.json`，重拼不丢。** `assemble.mjs` 每次拼接都按分镜节拍（或 `--align` 的 whisper）重排 `E0N.srt`，自动排错的句子（认不出、静音判断错）要手改。手改完 `E0N.srt` 后，**先不重剪**，马上跑一次 `assemble.mjs … --keep-subs`：它按台词原文找到改过的句子，把时间存成「从这一切剪点算起的秒数」，写进 `fix.json` 这一段的 `subs`（`{"E01-02": {"subs": {"哎呀老公，我把你落在餐厅了！": [2.55, 5.25]}}}`）。以后别的切剪长剪短、整集重拼，这几句都跟着剪点走；改了台词原文的句子对不上，会打印提醒（《跟谁吃的》重拼三次，每次都要手动拷回字幕，之后加了这个）。
- 剪掉后段的瑕疵比重出便宜：瑕疵出现得晚、台词已经说完时，在 `fix.json` 里把这一切剪短。
- **句中长停顿剪掉，用插入镜头盖住接口。** `cut.py` 只能掐头去尾。先用 ffmpeg 把原片里的停顿剪掉（留约 0.25 秒，画面和声音一起剪，重新编码），原片另存到 `_bak/video/`；再用分镜的 `cover` 把接口盖在一个插入镜头里，原来单独的插入镜头写进 `skip`（《老地方》01-2：1.6 秒停顿盖在婚戒特写里）。
- `speed` 是这一切的提速系数，画面和声音一起加速，音高不变。竖屏短片按 `writing.md` 第 5 节的节奏写：纯动作镜头 ×1.4–2.0。Grok 原声的对白切默认 ×1.3：《改口费》按 1.0 剪，用户说「语速也太慢了」，有台词的切提到 1.3 倍才过；不说话的反应切保持 1.0，留给观众反应。嘴在画面里本来就动得快的切（《改口费》s2、s8），画面也保持 1.0。提示词里写语速词基本没用：《赊账》试探 s6 写了「talking fast and sharp, quick snappy delivery」，原片只快一点，用户两次说慢；剪成 1.3 倍才过。试探镜头直接按 1.3 倍剪好再给用户听。
- **核对音画同步。** `cut.py` 和 `assemble.mjs` 出片后会比对音轨和画面的长度，差超过 0.25 秒就停。只比总长抓不住中途的错位，自己另做后期时还要核对：
  1. 看 `ffprobe` 给的音轨和画面的 stream 时长。不要用帧数除以 24，变帧率的片子会算错。
  2. 找几处画面和声音一起变的地方，比如切镜头时台词起头、灯亮时的跺脚声。按时间取帧（`ffmpeg -ss 秒数`），不按帧序号取；再用音量包络找声音起点。两者应落在同一帧内。

  拿字幕时间去对音量包络不算核对：两者都是按计划时间排的，对得上只说明自洽（《加油》第一版就是这样漏掉了 0.3 秒的错位）。

  **拼接的坑。** 段视频里音轨的时间戳常和实际声音对不上，比如容器写 22.3 秒，解出来只有 22.229 秒。按时间戳拼接（concat 清单，或再加 `aresample` 补齐）都会让后面的声音越来越早或越来越晚。`assemble.mjs` 的做法是：每段画面补到或截到 n 帧，声音按采样数补静音或截断到同样的 n/24 秒，两条各自首尾相接。`cut.py` 在段内对每一切做同样的事：时长先取整到 1/24 秒，画面补到或截到这么多帧，声音补到或截到同样长度再拼。不这样做，提速镜头之后画面会越拖越晚：《大水》第 1 段末尾声音比画面早约 0.1 秒。不要用"按帧号重写时间戳 + 强制恒定帧率"去补画面的空隙，这样会丢帧：《加油》第四版试过，后面 276 帧没了。`cut.py` 里每切声音最后用 `asetpts=N/SR/TB` 按采样数重算时间戳：做过 `loudnorm` 的切，声音时间戳会跳一下，`concat` 据此把下一切往后推约 2 帧，剪点留空档，后面的字幕越来越晚（《改口费》结尾差 0.58 秒，《干拌吗》也有）。

  **先用 Grok 原声。** 《改口费》把 MiMo 配音版和 Grok 原声版同一套剪辑给用户比，用户说「grok 原声完胜」：Grok 的声音和嘴形是一起生成的，语气也更像真人。原声吞字、念错时，先重交那一切（《改口费》s6 吞了「爸妈」的「爸」，重交两条都说全了）。只有重交也念不对、或必须沿用老演员的声音时，才换配音。换配音时注意三点：
  - `--style` 只写几个字（「惊喜，热情」）。写长了，克隆出来会带口音，用户说像「外国人说中文」。
  - `--model design` 设计出来的样音不是真人录音，克隆它容易带偏口音；克隆前先出一句短台词让用户听。
  - 每句出 3 版，挑自然长度最接近口型的，`fit` 的伸缩控制在 0.85–1.15 倍。压到 1.3 倍以上，听着会发虚。
- **换配音：Grok 出画面和口型，声音用 MiMo 克隆（可选）。** Grok 念错字（《干拌吗》「蚯蚓」念成「手引」）、嗓音不对，或要沿用老演员的声音时用。集级 `mute: true` 关掉 Grok 的声音，每句配音在集级 `audio` 里挂一条。步骤：
  1. 截样音：从老演员以前的单人台词切里截 5–10 秒，只要这一个人说话，没有音乐和别人的声音。几段拼起来，去掉中间的静音。
  2. 出配音：`python3 scripts/dub.py say --model clone --voice ref-C01.wav --style "语气" --text "台词" -o L1.wav`，每句出两版。`--model design` 按文字描述设计新嗓音，`--model tts` 用预设音色。密钥读环境变量 `MIMO_API_KEY`。一次只发一条，同时发会被限流（429）。
  3. 量口型：`dub.py segs video/E01-01/s3.mp4` 给出 Grok 每句开口、收口的秒数。
  4. 对齐：`dub.py fit L1.wav --from 起 --to 止 --dur 口型时长 -o audio/dub/L1.wav`。伸缩超出 0.75–1.35 倍时，换一版配音或改剪点。`at` = 这一切在整集里的起点 + 开口秒数 − `fix.json` 的 `in`。
  5. 字幕按配音实际的时间手改 `E0N.srt`，再跑 `--keep-subs`。
  6. 转写配音核字，比核 Grok 的发音可靠；嗓音像不像，交给用户听。
- **靠声音反转的戏，声音全在后期做。** 《电视声》的反转是「暂停后，免提里的电视声晚一下才停」。电视屏幕不入画（侧对镜头，只拍电视光打在脸上），Grok 提示词写「no TV sound」。电视节目用 MiMo 配新闻播音腔，后期混两层：屋里电视全程，有人说话时用 sidechain 压低；免提里同一档节目晚 0.15 秒、加听筒滤波（450–3200 Hz），从按下免提那一帧开始。按暂停那一帧逐帧看准，屋里电视当场停，免提晚约 0.3 秒停。屋里那层要比免提响约 9 分贝，否则听不出停了两次。混音脚本从 `video/E01-01.shots.json` 读每切起点，剪辑改了长度不用手动重对时间（`works/电视声/_logs/mix-tv.sh`）。
- **留悬念的结尾也要有落点。** 《十八万八》原剧本停在李娟的反问「那结了婚，我住毛坯房？」就切黑，用户说「结束的很草率，突然就断了」。反问或抛出问题之后，接被问的人一个不说话的反应（约 2 秒：嘴张了又闭、垂眼、攥紧手），再接一个拉远的全景（约 3 秒：两人各看一边，镜头慢慢往后拉），然后切黑。问题照样不回答，观众有时间把它咽下去。落地检查时就要问：最后一句说完，画面停在哪？
- **结尾补切要同时补 script.json 的 beat。** 不说话的切在 script.json 里加 `act` beat，storyboard 的 `beats` 指向它。直接复制别的切会把那切的 `beats` 一起带过来，台词就跑进字幕。补完重跑 `cut.py` 前确认 `video/prompts.json` 里也有新切（这部提示词只写在 `_logs/short-all.json`，`cut.py` 报缺 prompts.json）。
- **Grok 页面会变成英文，提交脚本中英文按钮名都要认。** 《十八万八》提交中途 Grok 退出登录（弹出「创建您的账户」），用户重新登录后界面变成英文：Submit/提交、Video resolution/视频分辨率、Video audio/视频音频。按 `aria-label` 找按钮时两种都写。遇到退出登录，停下请用户登录，账号密码不替用户填。
- **撤片原样重交一次。** 《十八万八》s6、s11 生成完后帖子消失、下载 404，提示词和别的切没什么区别，原样重交都过了。批量提交完尽快下载。
- **同一切撤片两次，换首帧再交。** 《好邻居》s5 原样重交后又被撤。第三次换成同机位、表情平静的首帧（她没泛泪的 f3），情绪词从「越说越感动」改成「温暖感激地笑」，过了。
- **把东西拿走的动作，写明几秒内拿完、对方不转身。** 《好邻居》结尾小美把蛋糕端回来，第一版原片到 3 秒才拿完，林浩 3.3 秒就转身对着镜头，能剪的只有 0.3 秒，用户看到「蛋糕还在两个人手上」。重出时写「0.5–1.5 秒端回胸前，1.5 秒起蛋糕只在她手里；他空手停在半空，一直看着她，不转向镜头」。剪完逐帧核：最后一帧东西在谁手里。
- **场景默认往干净、新一档走。** 《好邻居》剧本写「老小区楼道」，第一版照搬出了绿墙裙、斑驳白灰、铁皮门，用户说「房子能不能新一点」。除非剧情要旧（年代戏、穷困），楼道、客厅、店面都写成近几年的新装修。
- **出图用 Images 2.6。** 默认模型是 `openai/gpt-image-2.6-sunburst`（2026-11-04 发布）。《好邻居》28 次调用全部成功，每张约 30 秒，尺寸按传的出。服务不认这个模型时 frames.mjs 自动退回 `fallbackModel`，但 2.5 不带日期的版本只出 941×1672，出完看一眼尺寸。
- **`--only` 是正则，写到结尾。** 写 `frame:E01-01/f1` 会把 f1、f10、f11 一起出，f10、f11 拿不到 f1 当参考。要单出 f1 写 `f1$`。
- **AI 演员不能按调唱歌，唱歌的戏改成放录音或念出来。** 《生日》原剧本骑手在楼道里清唱生日歌。Grok 唱了两次（第二次只唱一句、放慢、每字落音），MiMo 配音唱了一次，三次都不在调上，用户说「唱的完全不对」。改成骑手用手机外放一段八音盒生日歌：旋律按谱用正弦波合成（公有领域旋律），加 500–4500 Hz 滤波当手机外放，后期混进这一切；Grok 提示词写「no music at all, no singing, no humming」，人物只举着手机跟节奏点头。转写只能核对字，核对不了调：要确认唱对了，量音高曲线对照谱子（生日歌第一句是 0 0 +2 0 +5 +4 个半音）。
- **Grok 一次提交出两条视频。** 帖子编号只对应其中一条，另一条在资料库里，编号不一样。要两条都拿，就在资料库页面取出编号，按首帧和 `frames/` 逐张比对认领；挑没烧字幕、表演更好的那条（《生日》s5 一条烧了字幕，用另一条）。取视频按帖子编号拼地址，不取帖子页上第一个播放器：页面会残留之前作品的视频，《生日》第一次就下成了《好邻居》的结尾。
- **浏览器一批最多提交 2 切。** 《生日》一批塞 4 切超时，工具没返回编号。超时后去资料库看上传的首帧和生成的视频，确认没漏、没重复，再按首帧认领编号，不要原样再交一遍。
- **改了设定，重新评估原剧本里的旁人反应。** 《生日》原剧本写「隔壁门开了一条缝，又关上」，是深夜清唱吵到邻居。改成手机外放后理由变弱；门缝只在虚化背景里，大多数人看不出来，看出来的又容易当成悬疑伏笔（《电视声》用门缝表示有人偷看）。用户问「想表达什么」后删掉。原剧本里只出现在背景里的小动作，落地检查时问一句：观众看得到吗，会不会看歪？
- **靠观众推算的揭底，要有人把它说出来。** 《我的妈妈》原剧本最后一句是作文里的「我妈妈今年六十三岁了」，要观众自己算出 27 岁的妻子不是作文里的妈妈、写的是奶奶。用户第一遍看完问「妈妈 63 岁了是什么意思」，也看不懂揭底前丈夫为什么先收住笑。给丈夫补一句低声的「那是咱妈」后才落地。落地检查时问一句：不加解释，观众能一遍看懂吗？看不懂就给另一个角色补一句短台词，不要只靠数字或细节。
- **两人语速不一样，提速按人分。** 《我的妈妈》丈夫按 1.3 倍仍嫌慢，他的台词单独改 1.5 倍，妻子留 1.3 倍。`fix.json` 的 `speed` 逐切写。
- **「躺下」写完整的身体位置。** 坐在床边躺下，只写「侧身躺下」，Grok 画成上身趴下、腿垂在床下。要写「抬起双腿放到床上，屈膝侧躺，身体和腿都在床上，没有东西垂在床边」。
- **首帧改图删掉的道具，提示词里同步删。** 《我的妈妈》f12 改图去掉了安全帽，提示词还写着「床头的安全帽」，安全帽就扣到了她头上。改完首帧，把这一切的提示词再对一遍。
- **清元数据核对时原片在前。** `video-scrub.mjs verify <原片> <成片>`；写反会多报「设备与软件标识」「码流身份串」两项红。
- **跨切的伤、妆、污渍写死一处。** 写清哪条胳膊、哪个位置、多大、什么样（《红药水》：「左小臂肘弯下方一小块擦伤」），首帧逐张放大对左右臂和大小；状态按剧情变（擦伤 → 红药水 → 纱布），位置和大小不变。用户连指两次「手臂不是同一边」「一会有伤一会没伤，伤的程度还不一样」。
- **Grok 会自己加伤。** 《红药水》01-11 说着话上臂冒出擦伤，01-3 手腕多一道红线。有伤的戏每条提示词写「只有首帧里那一处伤，身上其他地方不加任何伤痕和血」，下载后放大看每切的胳膊。
- **台词问到的动作，前一切要真做出来。** 《红药水》她问「缩啥」，原 01-3 他伸了胳膊就停住，没往回收。落地检查和看片时逐句对：台词提到的动作，画面里有没有。
- **带血的首帧走 Grok 改图。** OpenAI 把伤口判成「自残/暴力」，参考图带血时改写文字也会拒；伤口写小、不写流血，再拒就直接用 Grok。
- **几乎无声的切，降噪后再把无声段压低。** 《红药水》01-12 打结两秒几乎无声，逐切拉平把杂音抬到和台词一样响。降噪加重，打结、剪纱布这类无台词段单独压低音量。
- **年代戏先不加年代花字。** 服装、道具、场景能交代年代就不加，用户要再加（《红药水》用户说「不需要打 1977 的字幕」）。
- **换了素材重剪，从切片跑起。** 只重拼会用旧段落缓存，换进去的切不生效；拼完抽帧核对换进的切。
- **「码流身份串」偶尔是巧合。** 清元数据报「码流里有 Lavc 1 处」时，看这 4 个字节前后：前后都是乱码，是压缩数据碰巧拼出，不是软件标记（《红药水》）。
- **带数字的词 Grok 会吞字，写成阿拉伯数字。** 《两千件》「双十一」两次念成「双一」。台词写成「双11」并注明 `Read 11 as shi yi`，才念出「十」。有数字的台词，试探或下载后先转写核对。
- **改台词重做的切，防烧字幕的写法一起加。** 《两千件》s8 改成「那你就别干了」重做，没加手上动作，字烧在胸口。新台词按新切处理：提示词开头写「台词只能听见，不许写在画面上」，手上安排动作。
- **字幕晚出现就剪掉，前景的人说完会转身也一样剪。** 《两千件》s1、s8 的字分别到 4 秒、1.5 秒才烧出来，s12 说完后前景的她转过头。台词说完就剪，前面那段能用，不必一直重做。
- **话说一半咽回去，落地检查时补成完整一句。** 《两千件》「那你……」用户看不懂她咽回去的是什么，改成「那你就别干了」，下一句正好接住。
- **切变短后，`--keep-subs` 会沿用旧字幕时间。** 改了 `fix` 之后，按新切点重写字幕时间再拼（《两千件》）。
- **原片底噪先降再剪。** Grok 原片常带风声、蝉鸣，`--loudnorm` 逐切均衡会把台词间隙一起抬到 -43 dB 左右，用户听得出来（《地瓜干》）。给原片音轨做 `highpass=f=90,afftdn=nr=24:tn=1`，画面 `-c:v copy`，原声留在 `_bak/versions/`。台词间隙降 6–10 dB，转写不受影响。提示词里也少写环境声。
- **跨年代跳转要有转场。** 《地瓜干》1975→2025 硬切，用户要特效。做法：前一切尾段约 0.9 秒褪成泛黄老照片（褐色矩阵、颗粒、暗角，在 `rgb24` 下做；在 yuv 或 gbrp 下做会发青灰），再接 0.8 秒闪白（`transition: fadewhite`）进新年代，年份花字在白光退去后淡入。
- **核首帧和成片时看脚。** 《地瓜干》s13 两人光脚，全景穿黑布鞋，裁掉底部 14% 才对上。
- **聊天消息要配画外音。** 只有气泡，用户说「画面太安静」（《换号》）。陌生人、骗子用一个和剧中人都不像的声音（MiMo design，写「吐字清楚」，写「压着嗓子」会糊字），再做成手机听筒音色：`highpass=f=300,lowpass=f=3600`，加约 7 dB。剧中人自己发的消息用她的克隆声。画外音和气泡同时出现，逐条转写核字。
- **剧中人自己念出消息，气泡就不用再配画外音。** 《李总》小周边念边弹气泡，她的声音就是画外音。气泡贴着手机放（`x 0.40, y 0.66`，尾巴朝她），别压在脸旁边：第一版写 `y 0.5`，挡到了她的脸侧。
- **隔着玻璃说话用低通。** 原声加 `lowpass=f=2200,volume=0.8`，就有隔一层的闷声，口型不受影响（《李总》s13）。
- **反转靠「回头」时，第一镜就把答案放进画面。** 机位让揭底的人一直在主角身后，单人反打也留着虚焦的他；回头的动作不拍，改成越过她后脑看向身后，她的后脑不动（Grok 拍定向转头不可靠）。《李总》李总从 S01 起一直在玻璃墙里扒饭。
- **全景双人镜头也要给两人手上安排事。** 全景台词照样会烧字幕（《李总》s1 全程烧在画面中间）：说话的人和听的人都写清手放在哪里，台词去掉空格。
- **剧本里的职业动作，落地检查时按现实核一遍。** 《面试》剧本写「陈静低头写」，我照搬成在纸上编程，用户问「编程为什么是用纸和笔」。数控编程、记账、设计、做表现在都在电脑上做。落地检查时把每个职业动作和现实对一下，该用电脑就把电脑写进场景和首帧；屏幕始终不朝镜头（侧面看机壳、过肩看背面），说完合上。
- **某个字 Grok 总念偏，台词换成同音字。** 《面试》「螺丝」两次转写成「罗席」「罗系」，提示词注明 luó sī 也没用；台词写成「拧螺思的」才念对。字幕照写原词。同一个词两次转写都偏，就当成念错，直接换字重做，不要只请用户听。
- **改了分镜画面，先重建任务单再重出首帧。** `frames.mjs` 按 `tasks.json` 里存的描述出图：改完 `storyboard.json` 先跑 `plan --work $W --eps $EP --force`，再 `batch --only '/fN$' --redo`。《面试》漏了 `--force`、又漏了 `--eps`，白出 4 张旧图。
- **竖版封面从不带字幕的 `video/E0N.mp4` 截帧。** `E0N.final.mp4` 和成片都烧着字幕。
- **过肩镜头边缘的人，写「全程不动、脸不进画面」。** 只写「不转身」不够：《梦游》s3 右边缘虚焦的室友从 1 秒起往里探头，露出半张侧脸，用户说「扭头太诡异」。写明边缘只露头发和肩膀，全程一动不动，不往前凑、不动头，脸始终不进画面。下载后检查也要看边缘，不只看烧字幕和左右位置。
- **画面里的录像（监控、手机视频）单独拍成全屏插入镜头。** 不拍屏幕，免得冒乱字。时间码、机位号后期用 drawtext 加；原片无声就混一层环境声。要「转过身来」露脸，拆成背影一切、走向镜头抬头一切，不写原地转身。
- **拉片时场景检测会漏同机位、同色调的切点。** 《梦游》两段监控之间、两个同机位全景之间都没检出来，对着剪辑的切点表用 `recut --split` 补刀。
- **Grok 连不上，先查是不是 xAI 的域名全断了。** grok.com、x.com、assets.grok.com、api.x.ai 一起断而 Google、GitHub 正常，是代理线路问题：停下来请用户换线路，不要反复重试。
- **低头对着手机说话，和对着纸念一样会烧字幕。** 《每月两千》s2 刘敏低头看手机说「我弟上大学，生活费」，两版都烧了字幕，加拇指划屏幕也没用。第三版改成她 0 秒把手机放到腿上、眼睛移开看台灯再说，一次过。说话时眼睛要离开屏幕。
- **小动作压不住烧字幕时，换一个大动作。** 《每月两千》s12「你爸不是也有地吗」：手搭被子、手里慢慢翻手机，两版都烧了。改成 0 秒把手机丢到被子上、两手抱胸、歪一下头，一次过。同片 s7、s9、s11 提前写「手一直在动」、去掉台词里的逗号，三条都一次过。
- **过肩首帧里边缘的人已经露出侧脸，提示词压不住。** 《每月两千》s13 首帧右边缘本来就有王磊虚焦的眼和鼻，写了「脸不进画面」「头停在首帧位置」，两版照样有。审首帧时就看边缘：只该有头发和肩膀。
- **`--align` 排的字幕常比剪点早 0.1–0.2 秒。** 《每月两千》12 句里 11 句提前出现，下一句压在上一个人的脸上。拼完按每切起止，把字幕起点挪到剪点后约 0.04 秒、终点不过下一个剪点，再跑 `--keep-subs` 存进 `fix.json`。
- **无台词切换成底噪。** Grok 在没有台词的切里常自己配一句英文（《换号》s5、s13 两次），挑嘴不动的那段，声音换成同场景的底噪。
- **句尾拖长或多出字时，优先在旧版上剪。** 《换号》「你本来就没有有」重出变成「没有了」，回到旧版剪在「没有」刚说完处才干净。
- **`fix.json` 的 `fix` 是加速后的输出秒数**，不是原片秒数；按原片秒数填，片长会多出几秒。
- **交审图时同时放原图。** 审图拼版每格只有 360×640，用户会觉得糊；把 1152×2048 原图放进 `_review/首帧原图/`。

### 11. 定稿

```bash
node scripts/assemble.mjs --work $W --ep $EP --loudnorm --align
```

烧硬字幕，输出 `video/E0N.final.mp4` 和 `video/E0N.srt`。抽几帧检查字幕位置和文字。

片尾有 `fadeOut` 时，在分镜这一集写 `"tailBlack": 0.5`，淡到黑后再接 0.5 秒纯黑、静音（用户要求「别忘了黑屏淡出」）。`assemble.mjs` 会把它拼进整集，硬字幕版跟着带上，不用另跑 ffmpeg。

**封面**出两张：竖版 `封面-竖版.png`（1080×1920）和横版 `封面-横版.png`（1440×1080，4:3：用户 11-01 定），发布时单独上传。竖版可以截片中的帧；横版构图不同，用人物设定图当参考图单独出一张。两张都要做到：
- `frames.mjs` 出图时，文件名带「横版」的按 4:3 出（2048×1536），不跟作品画幅：`frames.mjs fix --raw --target 成片/封面-横版.png`。出完核一下尺寸，《赊账》第一次出成了竖图。
- 表情好看。截帧前先排一张缩略图总览，在近景里挑，不在全景里挑。
- 一眼认得出是哪部。画面里带上本片的标志：关键道具、场景、两个人的关系。只有一张好看的人脸近景，会和同一演员的其他片撞（《光坐着》第二张封面和《各论各的》几乎一样）。

截帧里没有合适的，就用设定图当参考图单独出一张（`frames.mjs fix --raw`，`--ref` 挂场景、人物、道具设定图）。要背景虚焦，把这张图当原图再 `fix` 一次，写「背景做浅景深虚焦，前景保持不变」；不要后期涂模糊。

### 12. 清理、复盘

用户确认后，删镜头原片和中间文件，只留成片、字幕和出片记录。然后按 `retro-template.md` 写复盘：只记和上一集不同的地方，以及原因。规则有变就改这几份 reference 文档。

**复盘前先拉片。** 用 [reelbench-skills](https://github.com/eternityspring/reelbench-skills) 的 `video-shots` 把成片拆成逐镜头的表，放在作品目录的 `_拉片/`。切点和时长由 ffmpeg 量，不用估；景别、画面和节奏角色看联系表填。

1. 在 `_拉片/` 里跑 `video-shots.mjs seed ../成片/<片名>.mp4 --track track.json --title "<片名>" > shots.json`。核对检测到的镜数：应该等于 `video/E0N-*.shots.json` 的切数加片尾黑屏。对不上就用 `recut` 补刀或并刀。同机位、同景别的相邻两切常被并成一镜（《赊账》s14、s15），对着审片版打印的切点表补刀。
2. 跑 `frames`、`sheet`（a 表和 b 表），看联系表填景别、类别、运镜、画面、台词，**节奏角色整片标全**（钩子、铺垫、递进、重音、转折、兑现、换气、收口）。
3. 跑 `validate --track track.json --frames frames`，15 道门全过。再 `render --md` 和 `render --html --video ../成片/<片名>.mp4`，出 `shots.md` 和 `shots-report.html`。
4. 要给人看对照视频，再跑 `video-sync.mjs export shots.json --video ../成片/<片名>.mp4 --frames frames -o <片名>-拉片对照.mp4`（竖片输出约 1580×1080，左画面右镜头表）。

拉片结果写进复盘的「拉片」一节：镜数、平均镜长、每分钟切次、节奏曲线、最长的一镜。清理时 `_拉片/` 留着（约 15 MB），`panels/` 可以删，能重跑出来。

**发布数据回来后对照拉片。** 用户发来 6、24、72 小时数据（2 秒跳出率、5 秒完播率、流失曲线）时，把流失明显的时间点对到 `_拉片/shots.json` 的镜头上，写进复盘的「数据对照」：那几秒是哪几镜、各是什么节奏角色、为什么会走。结论成立就改成规则写进 `writing.md`（《跟谁吃的》是第一部这样拉的）。

## 故事语言

故事可以是中文、英文或韩文，在 `project.json` 写 `"language": "zh" | "en" | "ko"`。脚本按它决定：

- 台词时长怎么算：中文、韩文按字（音节）数，英文按词数，除以语速再加 1 秒起音。
- 语音识别用哪种语言（`cut.py` 测台词说完的时间，`assemble.mjs --align` 对齐字幕）。
- 字幕的字体和换行：中文按字换行，英文、韩文按词换行。
- 提示词里的固定句子（限制、出镜人数、视线等），以及台词的语言名。

脚本打印的提示也有三种语言：默认跟着作品的故事语言，也可以用环境变量 `DRAMAZING_LANG=zh|en|ko` 指定。

**语速要用试探镜头校准。** 中文 3 字/秒来自《渡口》6 集。英文、韩文的值来自各一条试探镜头，样本很少（见 `langs.json` 的 `calibrated`）。新作品第一条试探镜头出来后：

1. 跑 `cut.py --work $W --ep 1 <试探镜头所在段号>`。这一段只有试探镜头也能跑：它只测台词、不拼段，打印台词起止秒数和「语速」（字数或词数 ÷ 开口到说完的秒数）。
2. 这个语速和 `langs.json` 的 `rate` 差得多，就在 `project.json` 写 `speechRate`。语速里含句间停顿，正好是排时长要用的值。

语速偏大，分镜给台词的时间就不够，剪辑会自动留长，整集会超出目标时长；偏小则反过来。
